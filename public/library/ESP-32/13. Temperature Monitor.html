02 // CONCEPTS

What Are We Learning?

Today we are learning about Smart Sensors and Libraries.

🧠

1. Smart Digital Sensors

The LDR from Project 12 was a relatively simple analog sensor. It changed resistance, which we converted into a voltage reading.

The DHT11 is different. It contains its own sensing and signal-processing electronics and communicates digital data to the ESP32.

When the ESP32 asks for a measurement, the DHT11 sends encoded digital information containing its temperature and humidity readings.

📚

2. Libraries — Borrowing Code

Reading the exact digital timing protocol of a DHT11 directly would require a lot of low-level code.

Instead, we use a library. A library is a bundle of reusable code written by other developers.

That lets us use simple commands such as dht.readTemperature().

⚡ The Big Idea

In Project 12, the ESP32 interpreted an analog voltage. In this project, the ESP32 communicates with a smart digital sensor and turns its digital response into useful scientific measurements.

05 // SOURCE CODE

Complete Code

Delete the default code and paste this in. Look at how short the application code is because the library handles the low-level DHT11 communication.

C++ 
/*
 * ============================================================
 * MY BRO'S THIRTEENTH ESP32 PROGRAM: TEMPERATURE MONITOR
 * ============================================================
 */

// 1. INCLUDE THE LIBRARY
// This tells the ESP32 to load the Adafruit DHT code.
#include "DHT.h"

// 2. CONFIGURE THE SENSOR
const int DHT_PIN = 4;        // DATA is connected to D4
#define DHT_TYPE DHT11        // We are using the DHT11 sensor

// Create our sensor "object" using the library.
DHT dht(DHT_PIN, DHT_TYPE);

void setup() {
    // Start the Serial Monitor.
    Serial.begin(115200);

    // Start the DHT sensor.
    dht.begin();

    Serial.println("Thermometer booting up...");

    // Give the sensor time before the first reading.
    delay(2000);
}

void loop() {
    // --------------------------------------------------------
    // READ THE DATA
    // --------------------------------------------------------

    // The library gives us simple commands for the readings.
    float temperature = dht.readTemperature();
    float humidity = dht.readHumidity();

    // --------------------------------------------------------
    // ERROR CHECKING
    // --------------------------------------------------------

    // isnan() means "is not a number".
    // It lets us detect an invalid sensor result.
    if (isnan(temperature) || isnan(humidity)) {
        Serial.println(
            "Failed to read from DHT sensor! Check your wires!"
        );
    }
    else {
        // ----------------------------------------------------
        // PRINT TO THE SCREEN
        // ----------------------------------------------------

        Serial.print("Temperature: ");
        Serial.print(temperature);

        Serial.print(" °C   |   Humidity: ");
        Serial.print(humidity);

        Serial.println(" %");
    }

    // The DHT11 is a slow sensor.
    // Wait before requesting another reading.
    delay(2000);
}
⏱️ Why 2 Seconds?

The DHT11 is a relatively slow sensor. It is not designed for rapid high-frequency readings, so the program waits between measurements.

Save your code with Ctrl + S.

06 // CODE DEEP DIVE

Understand the Code

📚

#include "DHT.h"

This tells the compiler to make the DHT library available to the program.

Once the library is installed, we can use the functions and classes it provides.

🔢

float temperature

Earlier projects often used int for whole numbers.

A float can represent decimal values, such as 24.5 or 25.1.

🛡️

isnan()

Sensor communication can fail. A function may return an invalid floating-point result.

isnan() checks whether the value is NaN — "Not a Number" — so we can print an error message instead of treating the invalid result like a real measurement.

📡

dht.readTemperature()

This asks the DHT library for the latest temperature measurement.

💧

dht.readHumidity()

This asks the DHT library for the latest relative humidity measurement.

⚙️

Sensor Object

DHT dht(DHT_PIN, DHT_TYPE); creates an object that represents our physical DHT11 sensor and its configuration.

🧠 The Pattern

Hardware → Library → Function Call → Useful Data.

That's a massive concept. Libraries let you work at a higher level without manually implementing every electrical communication protocol.

09 // EXPERIMENT

Celsius → Fahrenheit

What if you prefer Fahrenheit instead of Celsius? The library already supports it.

Find this line:

CURRENT CODE 
float temperature = dht.readTemperature();

Change it to:

MODIFIED CODE 
float temperature = dht.readTemperature(true);
🔄 What's Happening?

The true argument tells the library to return the temperature using Fahrenheit instead of Celsius.

Save the code, upload it again, and watch the Serial Monitor.

11 // DEBUGGING

Troubleshooting

❌

"Failed to read from DHT sensor!"

Check your wiring carefully.

DATA should go to D4. VCC should go to 3V3. GND should go to GND.

If your sensor is a 4-pin bare DHT11 rather than a 3-pin module, verify its exact pinout before connecting it.

📚

DHT.h Not Found

Check your platformio.ini. Make sure both lib_deps entries are present and correctly indented.

Save the file and allow PlatformIO to resolve the libraries.

📟

Serial Monitor Gibberish

Make sure the Serial Monitor speed is 115200, matching: Serial.begin(115200).

🔌

Intermittent Read Errors

Check for loose jumper wires and poor breadboard connections. The DATA connection is especially important because the sensor communicates through that line.

🧠 Debugging Rule

Don't immediately rewrite the code. First check the physical layer: power → ground → data → pin number → library.
