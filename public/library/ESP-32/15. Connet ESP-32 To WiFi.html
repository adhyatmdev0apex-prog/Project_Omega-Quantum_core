CONCEPTS

What Are We Learning?

Today we are learning three important networking concepts: network credentials, IP addresses, and the while loop used to wait for a connection.

📶
01 — SSID + Password

Your ESP32 needs the name of the Wi-Fi network, called the SSID, and the network password.

Important

The classic ESP32 DevKit V1 uses 2.4 GHz Wi-Fi. It does not connect directly to 5 GHz Wi-Fi networks.

🏠
02 — IP Address

When your ESP32 successfully joins the router, the router can assign it a local IP address such as 192.168.1.42.

Think of this as the ESP32's address on your local network.

🔄
03 — The while Loop

A while loop repeats its block of code as long as its condition remains true.

Here we use it to say: "Keep waiting until Wi-Fi connects."

🧠
Why This Matters

This is the first project where your ESP32 becomes part of a computer network instead of operating as an isolated microcontroller.

PROJECT 15 // 04 OF 14
CODE

Complete Code

Delete the default PlatformIO code and replace it with the following program.

Critical Step

Replace YOUR_WIFI_NAME and YOUR_PASSWORD with your actual Wi-Fi details. Keep the quotation marks.

C++ // src/main.cpp 
/*
 * ============================================================
 * MY BRO'S FIFTEENTH ESP32 PROGRAM: WI-FI CONNECTION
 * ============================================================
 */

// 1. INCLUDE THE WI-FI LIBRARY
// This library is built into the ESP32-Arduino core,
// so we do not need to download it.
#include <WiFi.h>

// 2. NETWORK CREDENTIALS
// Put your actual 2.4 GHz Wi-Fi Name and Password
// inside the quotation marks.
const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

void setup() {
    // Start the Serial Monitor so we can see
    // the connection process.
    Serial.begin(115200);

    // Give the Serial Monitor a split second to open.
    delay(1000);

    // Print a blank line, then announce we are starting.
    Serial.println();
    Serial.print("Connecting to network: ");
    Serial.println(ssid);

    // 3. START THE WI-FI RADIO
    // Tell the ESP32 to connect using your credentials.
    WiFi.begin(ssid, password);

    // 4. THE WAITING LOOP
    // WiFi.status() asks the radio if it is connected yet.
    //
    // "WL_CONNECTED" means success.
    //
    // "!=" means "IS NOT EQUAL TO".
    //
    // So this reads:
    // "WHILE the status is NOT connected,
    //  keep looping."
    while (WiFi.status() != WL_CONNECTED) {
        delay(500);

        // Print a dot every half second.
        Serial.print(".");
    }

    // 5. SUCCESS!
    // If the code reaches here, the while loop
    // finally finished.
    Serial.println("");
    Serial.println("🔥 Wi-Fi Connected Successfully!");

    // Ask the router what IP address our ESP32 has.
    Serial.print("ESP32 IP Address: ");
    Serial.println(WiFi.localIP());
}

void loop() {
    // We are not doing anything in the loop today.
    //
    // Once Wi-Fi connects in setup(), the ESP32
    // simply remains connected.
}
Save

Press Ctrl + S after entering your credentials and saving the program.

PROJECT 15 // 05 OF 14
DEEP DIVE

Understand the Code

This tiny program introduces some extremely important networking and programming concepts.

#include <WiFi.h>

This gives your program access to the ESP32 Arduino Wi-Fi API. It lets your code control the ESP32's wireless networking hardware.

const char* ssid

const char* is commonly used in Arduino C++ code to store a pointer to a text string.

In our program, it stores the Wi-Fi network name.

WiFi.begin()

This starts the process of connecting the ESP32 to the wireless network using the credentials we supplied.

WiFi.status()

This asks the Wi-Fi subsystem for its current connection status.

while

The loop repeatedly checks the condition. As long as the ESP32 is not connected, execution stays inside this block.

WiFi.localIP()

Once connected, this retrieves the local IP address assigned to the ESP32.

The important logic

C++ // logic 
while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
}

Read it almost like English:

Translation

"While Wi-Fi status is not connected, wait half a second and print a dot."

The moment the ESP32 becomes connected, WiFi.status() equals WL_CONNECTED. The condition becomes false, so the while loop ends and execution continues to the success message.

What that IP actually means

An address such as 192.168.1.42 is normally a local/private network address. It identifies the ESP32 within your local network.

It does not automatically mean that the ESP32 is directly exposed to the entire public Internet. That distinction becomes important as we build more advanced networking projects.

Why Does It Keep Printing Dots?

Because the router rejects the credentials. The condition WiFi.status() != WL_CONNECTED remains true, so the while loop continues.

Restore Your Password

Put your real Wi-Fi password back before continuing to the next project.

The lesson

You just observed something powerful: a program can intentionally wait for a condition to become true.

The same pattern appears everywhere in computing: waiting for hardware, waiting for data, waiting for a user, waiting for a network, and waiting for an event.

PROJECT 15 // 09 OF 14
CHALLENGE

Build a Wi-Fi Status Indicator

Right now, you need the Serial Monitor to know whether the ESP32 is connecting. Let's give the board a physical status indicator.

💡
Objective

Make the commonly used onboard LED on your ESP32 board blink while the ESP32 is trying to connect to Wi-Fi, then remain ON after the connection succeeds.

Requirements

  • You do not need a breadboard.
  • Use GPIO 2 if your particular ESP32 DevKit V1 board has its onboard LED connected there.
  • Add pinMode(2, OUTPUT); inside setup().
  • Inside the while loop, turn the LED ON and OFF around a short delay.
  • After the connection succeeds, set the LED HIGH so it remains ON.
Think Before Coding

The important part is understanding where each instruction goes. The blinking belongs inside the waiting loop. The solid ON instruction belongs after the loop has finished.

Hint

C++ // hint 
pinMode(2, OUTPUT);

while (WiFi.status() != WL_CONNECTED) {
    digitalWrite(2, HIGH);
    delay(100);

    digitalWrite(2, LOW);
    delay(100);

    // Continue waiting...
}

digitalWrite(2, HIGH);
Board Variation

ESP32 DevKit V1 boards and clones can differ. If GPIO 2 does not control an onboard LED on your particular board, use an external LED with a proper current-limiting resistor instead.

PROJECT 15 // 10 OF 14
DEBUG

Troubleshooting

Wi-Fi introduces a completely new category of problems. Work through these systematically.

Endless dots

Check the Wi-Fi name and password first. Remember that credentials are case-sensitive.

5 GHz network

Make sure a 2.4 GHz network is available. A classic ESP32 cannot directly join a 5 GHz-only network.

Typos

Check capitals, lowercase letters, spaces, underscores, and special characters in both the SSID and password.

Captive Portal

Hotel, university, airport, and similar networks may require a browser login page. Basic WiFi.begin() does not automatically handle that authentication flow.

Debugging checklist

  • Confirm the SSID exactly.
  • Confirm the password exactly.
  • Confirm that 2.4 GHz Wi-Fi is available.
  • Make sure the router is operating normally.
  • Try a phone hotspot configured to provide compatible 2.4 GHz Wi-Fi if available.
  • Make sure Serial Monitor is set to 115200.
Important Networking Detail

A successful Wi-Fi connection and Internet access are not exactly the same thing. Your ESP32 can join a local network even when the wider Internet is unavailable.

PROJECT 15 // 11 OF 14
VOCABULARY

New Vocabulary

These are the networking words you should now recognize whenever you see ESP32 Wi-Fi code.

SSID
Service Set Identifier. The technical name for a Wi-Fi network's name.
IP Address
Internet Protocol address used to identify a device on a network. The address printed by WiFi.localIP() is the ESP32's local network address.
<WiFi.h>
The ESP32 Arduino Wi-Fi API header used to access wireless networking functionality.
while loop
A programming loop that repeatedly executes its body while a specified condition remains true.
Router
A network device that connects devices and forwards traffic between networks.
Credentials
Information used to authenticate with a network, such as a Wi-Fi SSID and password.
Core Connection

Remember this chain: SSID + Password → Wi-Fi Connection → Router → Local IP Address
