🎯 What We're Building

We'll have three LEDs arranged from left → right:

LEFT RIGHT LED 1 LED 2 LED 3 💡 💡 💡 │ │ │ D2 D4 D5

The ESP32 repeatedly changes which LEDs are ON and OFF to create a small loading/progress animation.

Correct repeating sequence:
011 → 101 → 011 → 101 → ...

The RIGHT LED stays ON continuously. The OFF position alternates between the LEFT and MIDDLE LEDs.

🧠 2. What Are We Actually Doing?

Previously, one GPIO controlled one LED. Now three GPIOs are controlled independently.

GPIO 2 ──► LED 1 GPIO 4 ──► LED 2 GPIO 5 ──► LED 3

For example:

digitalWrite(2, HIGH);
digitalWrite(4, LOW);
digitalWrite(5, HIGH);

This combination turns the left LED ON, middle LED OFF, and right LED ON.

💡 3. Understanding 0 and 1

We represent each LED with a number:

0 = OFF    1 = ON

0,1,1 means LED 1 is OFF, LED 2 is ON, LED 3 is ON.

💡 6. LED Polarity

Usually:

  • Longer leg → positive side
  • Shorter leg → negative side

If one LED does not light, don't immediately assume the code is broken. Check the wiring and try reversing the LED.

🧠 7. Our Three GPIO Variables

Instead of writing 2, 4, and 5 everywhere, give each GPIO a descriptive name:

const int LED_LEFT = 2;
const int LED_MIDDLE = 4;
const int LED_RIGHT = 5;

Then digitalWrite(LED_LEFT, HIGH); immediately reads as “turn the LEFT LED ON.”

💻 11. Complete 3-LED Program

Paste this into main.cpp:

/*
 * ============================================================
 * MY BRO'S ESP32 — 3 LED LOADING SEQUENCE
 * ============================================================
 *
 * LED arrangement:
 *
 *       LEFT        MIDDLE        RIGHT
 *        LED 1        LED 2        LED 3
 *          │            │            │
 *         D2           D4           D5
 *
 * Sequence:
 *
 *       0,1,1
 *       1,0,1
 *       0,1,1
 *       ...
 *
 * 0 = LED OFF
 * 1 = LED ON
 *
 * The RIGHT LED stays ON while the OFF position alternates
 * between the LEFT and MIDDLE LEDs.
 *
 * ============================================================
 */

const int LED_LEFT = 2;
const int LED_MIDDLE = 4;
const int LED_RIGHT = 5;

void setup()
{
    pinMode(LED_LEFT, OUTPUT);
    pinMode(LED_MIDDLE, OUTPUT);
    pinMode(LED_RIGHT, OUTPUT);
}

void loop()
{
    // ========================================================
    // STEP 1: 0,1,1
    // LEFT = OFF
    // MIDDLE = ON
    // RIGHT = ON
    // Visual: ⚫  💡  💡
    // ========================================================

    digitalWrite(LED_LEFT, LOW);
    digitalWrite(LED_MIDDLE, HIGH);
    digitalWrite(LED_RIGHT, HIGH);

    delay(500);

    // ========================================================
    // STEP 2: 1,0,1
    // LEFT = ON
    // MIDDLE = OFF
    // RIGHT = ON
    // Visual: 💡  ⚫  💡
    // ========================================================

    digitalWrite(LED_LEFT, HIGH);
    digitalWrite(LED_MIDDLE, LOW);
    digitalWrite(LED_RIGHT, HIGH);

    delay(500);

    // loop() starts again automatically:
    //
    // 011 → 101 → 011 → 101 → ...
}

Save with Ctrl + S.

🧠 12. Understanding the Program

Don't worry about the comments. The actual program is simple.

LED_LEFT LED_MIDDLE LED_RIGHT ↓ GPIO 2 GPIO 4 GPIO 5 ↓ 011 → 101 → 011 → 101 → ...

First, the three LEDs are named. Then all three GPIO pins are configured as outputs. Finally, loop() alternates their states forever.

🔵 13. Why Do We Use pinMode() Three Times?

With one LED:

pinMode(LED_PIN, OUTPUT);

With three LEDs, configure three GPIOs:

pinMode(LED_LEFT, OUTPUT);
pinMode(LED_MIDDLE, OUTPUT);
pinMode(LED_RIGHT, OUTPUT);
GPIO 2 → control an LED GPIO 4 → control an LED GPIO 5 → control an LED

💡 14. How digitalWrite() Controls Each LED

HIGH turns the selected LED ON:

digitalWrite(LED_LEFT, HIGH);
LEFT LED → ON

LOW turns it OFF:

digitalWrite(LED_LEFT, LOW);
LEFT LED → OFF

The same idea applies to the middle and right LEDs.

🧩 15. Understanding 011

The first pattern is:

0,1,1

So:

LED 1 = 0 → OFF
LED 2 = 1 → ON
LED 3 = 1 → ON
LEFT MIDDLE RIGHT ⚫ 💡 💡

The code is:

digitalWrite(LED_LEFT, LOW);
digitalWrite(LED_MIDDLE, HIGH);
digitalWrite(LED_RIGHT, HIGH);

🧩 16. Understanding 101

Next:

1,0,1
LED 1 = ON
LED 2 = OFF
LED 3 = ON
💡 ⚫ 💡

The code:

digitalWrite(LED_LEFT, HIGH);
digitalWrite(LED_MIDDLE, LOW);
digitalWrite(LED_RIGHT, HIGH);

🔁 17. Then the Sequence Restarts

At the end of loop(), Arduino automatically starts loop() again.

011 ↓ 101 ↓ 011 ↓ 101 ↓ ...

This never stops while the ESP32 is running.

⏱️ 18. What Does delay(500) Do?

Between each pattern:

delay(500);

That means 500 milliseconds = 0.5 seconds.

011 ↓ 0.5 sec 101 ↓ 0.5 sec 011 ↓ 0.5 sec ...

🐢 19. Make the Animation Slower

Change:

delay(500);

to:

delay(1000);

Each pattern now stays visible for 1 second.

011 ↓ 1 sec 101 ↓ 1 sec 011 ↓ ...

⚡ 20. Make It Faster

Try:

delay(100);

Each pattern stays visible for 0.1 seconds. The LEDs appear to alternate much faster.

🧠 29. Important Concept — GPIO States

You have now learned:

GPIO
 ↓
OUTPUT
 ↓
HIGH / LOW

For example:

digitalWrite(LED_LEFT, HIGH);
Software ↓ GPIO 2 ↓ HIGH ↓ LED receives electrical output ↓ LED turns ON

And:

digitalWrite(LED_LEFT, LOW);
Software ↓ GPIO 2 ↓ LOW ↓ LED turns OFF

🧠 30. Why We Give Pins Names

Compare:

digitalWrite(2, HIGH);
digitalWrite(4, LOW);
digitalWrite(5, HIGH);

with:

digitalWrite(LED_LEFT, HIGH);
digitalWrite(LED_MIDDLE, LOW);
digitalWrite(LED_RIGHT, HIGH);

The second version immediately tells you what is happening. This becomes very important as projects grow to include buttons, sensors, displays, motors, buzzers, cameras, Wi-Fi, and more.

🚨 32. If One LED Doesn't Work

Test the LEDs individually. Temporarily change loop() to:

void loop()
{
    digitalWrite(LED_LEFT, HIGH);
    digitalWrite(LED_MIDDLE, LOW);
    digitalWrite(LED_RIGHT, LOW);
    delay(1000);

    digitalWrite(LED_LEFT, LOW);
    digitalWrite(LED_MIDDLE, HIGH);
    digitalWrite(LED_RIGHT, LOW);
    delay(1000);

    digitalWrite(LED_LEFT, LOW);
    digitalWrite(LED_MIDDLE, LOW);
    digitalWrite(LED_RIGHT, HIGH);
    delay(1000);
}
💡 ⚫ ⚫ ↓ ⚫ 💡 ⚫ ↓ ⚫ ⚫ 💡 ↓ ...

If one particular LED doesn't light, check its wire and GPIO connection.

🔄 33. If an LED Is Backwards

If the GPIO is working but the LED doesn't light, reverse the LED.

LONG LEG ↓ positive side SHORT LEG ↓ negative side

🚨 34. If the ESP32 Doesn't Upload

USB cable

Make sure it's a data cable, not charge-only.

USB port

Try another USB port.

BOOT button

If the upload can't connect, try holding the BOOT button while PlatformIO starts connecting.

Don't randomly change upload speeds. The project uses a normal 115200 serial monitor speed.

🧠 35. One Important Thing About the Pins

We're deliberately using:

D2
D4
D5

These correspond to:

D2 → GPIO2
D4 → GPIO4
D5 → GPIO5

As you learn more ESP32, you'll discover that some GPIOs have special roles during boot or other hardware functions. For now, keep the wiring exactly as specified.
