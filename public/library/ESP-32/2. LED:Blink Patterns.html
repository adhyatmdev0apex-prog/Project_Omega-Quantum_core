🧠 Timing & delay()

The ESP32 reads your program from top to bottom, one line at a time. The delay() function tells it to wait before continuing.

The key idea

LED ON → SHORT DELAY → LED OFF → LONG DELAY

Change the lengths and order of those delays, and you create a pattern. Patterns let a simple light communicate information.

100 ms

0.1 seconds — a very short pulse.

150 ms

0.15 seconds — slightly longer.

1000 ms

1 second — a noticeable rest.

Pattern

A specific sequence of ON and OFF states.

📄 Complete Code

Delete everything inside main.cpp and paste this program. This program simulates a human heartbeat.

C++ · main.cpp 
/*
 * ============================================================
 * MY BRO'S SECOND ESP32 PROGRAM: THE HEARTBEAT
 * ============================================================
 */

// Tell the ESP32 that our LED is on GPIO 2
const int LED_PIN = 2;

void setup()
{
    // Configure the pin to push electricity OUT
    pinMode(LED_PIN, OUTPUT);
}

void loop()
{
    // --------------------------------------------------------
    // FIRST BEAT (Quick pulse)
    // --------------------------------------------------------
    digitalWrite(LED_PIN, HIGH);   // Turn ON
    delay(100);                    // Wait 100 milliseconds (0.1 seconds)

    digitalWrite(LED_PIN, LOW);    // Turn OFF
    delay(100);                    // Wait 100 milliseconds (0.1 seconds)

    // --------------------------------------------------------
    // SECOND BEAT (Slightly longer pulse)
    // --------------------------------------------------------
    digitalWrite(LED_PIN, HIGH);   // Turn ON
    delay(150);                    // Wait 150 milliseconds (0.15 seconds)

    digitalWrite(LED_PIN, LOW);    // Turn OFF

    // --------------------------------------------------------
    // REST (Wait for the next heartbeat cycle)
    // --------------------------------------------------------
    delay(1000);                   // Wait a full 1000 milliseconds (1 second)
}
Press Ctrl + S to save.

🧠 Understand the Code

Look closely at how we used delay().

Project 01 vs Project 02

In Project 01, we used delay(2000) to wait for 2 full seconds. Here, we use much smaller numbers to create a rhythm.

Code Meaning
delay(100) 100 milliseconds = 1/10th of a second.
delay(150) 150 milliseconds = slightly longer than 1/10th.
delay(1000) 1000 milliseconds = 1 full second.
FIRST BEAT
SECOND BEAT
REST
Sequential execution: ON → wait → OFF → wait → ON → wait → OFF → long rest → repeat.

🔥 Challenge: S.O.S.

Your Objective

Modify your loop() so the LED broadcasts an S.O.S. distress signal using Morse Code.

S = 3 quick flashes
O = 3 slow flashes
S = 3 quick flashes

Quick flash

Try delay(200).

Slow flash

Try delay(600).

Between flashes

Turn the LED LOW and give it enough time to be physically OFF.

Repeat pause

Use delay(2000) at the bottom.

Hint: You will need to write many digitalWrite() and delay() calls in a row. Don't forget the long pause at the bottom of the loop.

🐛 Troubleshooting

Code didn't change the LED

Did you press Ctrl + S before clicking Upload? If you don't save, PlatformIO can upload your previous saved code.

The flashes blend together

During the SOS challenge, make sure you put a delay() after turning the LED LOW. Your eyes need time to see the gap.

Nothing lights up

Recheck the Project 01 wiring: long LED leg → D2 and short LED leg → GND.

Upload fails

Check the USB connection and confirm PlatformIO is targeting the correct ESP32 board and port.
