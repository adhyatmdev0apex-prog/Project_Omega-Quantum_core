02 / Concepts

What Are We Learning?

1. Multiple GPIO Outputs

Your ESP32 doesn't just have one pin. It has dozens of GPIO pins.

Each GPIO can be configured as an OUTPUT and controlled individually.

GPIO Mental Model

Think of every GPIO as a tiny controllable switch. You can tell one switch to turn ON, another to turn OFF, and another to turn ON again.

2. How a Breadboard Works

A breadboard lets you connect wires and components without permanently soldering them.

Underneath the plastic holes are small metal clips that connect certain holes together.

Golden Rule

The middle holes are connected in groups. Your exact breadboard layout determines which holes share a connection, so always inspect the board's markings and internal connection pattern.

Power Rails

Many breadboards have long rails along the sides marked with + and −.

We will use the blue / negative rail to share one Ground connection between the ESP32 and all three LEDs.

03 / Wiring

Build Your First Multi-LED Circuit

Take your time here. Hardware mistakes are much easier to prevent than debug.

Step 1 — Place the ESP32

Carefully push your ESP32 into the breadboard so it straddles the deep trench running down the middle.

This keeps the pins on the two sides from accidentally sharing the same electrical row.

Step 2 — Share Ground

Take a jumper wire. Connect one end to a GND pin on the ESP32.

Connect the other end to the blue − rail on the breadboard.

Step 3 — Connect the LEDs

LED Orientation

Long leg = Positive
Short leg = Negative

05 / Firmware

Complete Code

Delete everything inside main.cpp and paste this program.

C++ / Arduino 
/*
 * ============================================================
 * MY BRO'S THIRD ESP32 PROGRAM: MULTI-LED ANIMATION
 * ============================================================
 */

// Give our three pins easy-to-read names
const int LED_LEFT = 2;
const int LED_MID = 4;
const int LED_RIGHT = 5;

void setup()
{
    // We must tell the ESP32 that ALL THREE of these pins are outputs!
    pinMode(LED_LEFT, OUTPUT);
    pinMode(LED_MID, OUTPUT);
    pinMode(LED_RIGHT, OUTPUT);
}

void loop()
{
    // We create a variable to hold our wait time.
    // Now we only have to change this one number to speed up or slow down!
    int waitTime = 300;

    // --------------------------------------------------------
    // PATTERN 1: (0 1 1)
    // Left is OFF, Mid and Right are ON
    // --------------------------------------------------------

    digitalWrite(LED_LEFT, LOW);
    digitalWrite(LED_MID, HIGH);
    digitalWrite(LED_RIGHT, HIGH);

    // Wait so we can see it
    delay(waitTime);

    // --------------------------------------------------------
    // PATTERN 2: (1 0 1)
    // Left is ON, Mid is OFF, Right is ON
    // --------------------------------------------------------

    digitalWrite(LED_LEFT, HIGH);
    digitalWrite(LED_MID, LOW);
    digitalWrite(LED_RIGHT, HIGH);

    // Wait so we can see it
    delay(waitTime);

    // --------------------------------------------------------
    // The loop restarts!
    // --------------------------------------------------------
}
Save

Press Ctrl + S after pasting the code.

06 / Code Analysis

Understand the Code

Why Use Names Instead of Numbers?

Instead of repeatedly thinking about GPIO numbers, we created readable names:

C++ 
const int LED_LEFT = 2;
const int LED_MID = 4;
const int LED_RIGHT = 5;

Now this: 

digitalWrite(LED_LEFT, HIGH);

is much easier to understand than: 

digitalWrite(2, HIGH);
Why This Matters

If you move the left LED from GPIO 2 to another pin later, you only change the number at the top of the program.

The waitTime Variable 

int waitTime = 300;

Instead of writing delay(300) everywhere, we write: 

delay(waitTime);

Change one number and the entire animation changes speed.

setup()

Every LED pin must be configured as an OUTPUT. 

pinMode(LED_LEFT, OUTPUT);
pinMode(LED_MID, OUTPUT);
pinMode(LED_RIGHT, OUTPUT);

loop()

The loop creates the animation frames.

The ESP32 sets all three LED states, waits, changes the states, waits again, and then starts over.

11 / Debugging

Troubleshooting

One LED Isn't Lighting

Check your breadboard wiring.

If the LED is in one numbered row but the GPIO wire is in another, they may not be electrically connected.

All LEDs Are Dark

Check the Ground connection.

Your breadboard Ground rail must connect back to a GND pin on the ESP32.

LED Is Still Dark

Check the direction of the LED.

Remember

Long leg → GPIO output
Short leg → Ground

Animation Is Wrong

Check that every frame sets the state of all three LEDs.

If one LED isn't explicitly changed, it can keep its previous state.
