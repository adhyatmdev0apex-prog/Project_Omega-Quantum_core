03 // New Systems

What Are We Learning?

Three massive concepts are joining together.

01 // Analog Input

A potentiometer is a variable resistor. As you turn the knob, the voltage on its middle pin changes.

Instead of simply reading HIGH or LOW, analogRead() gives us a numerical measurement.

INPUT 0–4095 ADC
02 // PWM Output

A microcontroller doesn't create a true "half-power" digital output.

Instead, PWM rapidly switches the output ON and OFF. The percentage of time it is ON changes the perceived brightness.

PWM 0–255 BRIGHTNESS

04 // Hardware Wiring

Connect the Circuit

The potentiometer is our analog sensor. The LED is our visual output.

Potentiometer
  • Push the potentiometer firmly into the breadboard.
  • Make sure the three legs are in different rows.
  • Left leg → ESP32 3V3
  • Middle leg → ESP32 D34
  • Right leg → Blue GND rail
LED
  • ESP32 D24 → resistor → LED long leg
  • LED short leg → Blue GND rail
  • Connect an ESP32 GND pin to the Blue GND rail.

D34 Reminder

D34 is an input-capable ADC pin on the ESP32 DevKit V1 and is a good choice for this potentiometer reading. It is input-only, so don't try to use it as an LED output.

06 // Core Firmware

Complete Code

Delete the default code and paste this in. Read the comments carefully.

C++ 
/*
/*
 * ============================================================
 * MY BRO'S TENTH ESP32 PROGRAM: ANALOG & SERIAL MONITOR
 * ============================================================
 */

const int POT_PIN = 34; // The pin connected to the middle of the knob
const int LED_PIN = 25; // The pin connected to our LED

void setup()
{
    // 1. START SERIAL COMMUNICATION
    // Tell the ESP32 to talk to the PC at 115200 baud.
    Serial.begin(115200);

    // Configure the LED as an output.
    pinMode(LED_PIN, OUTPUT);

    // GPIO 34 is an analog input.
    // analogRead() does not require pinMode() here.
}

void loop()
{
    // --------------------------------------------------------
    // STEP 1: READ THE ANALOG VALUE
    // --------------------------------------------------------

    // With the default 12-bit resolution,
    // analogRead() returns a value from 0 to 4095.
    int potValue = analogRead(POT_PIN);

    // --------------------------------------------------------
    // STEP 2: MATHEMATICS (MAPPING)
    // --------------------------------------------------------

    // Convert the ADC range into the PWM range.
    int pwmValue = map(potValue, 0, 4095, 0, 255);

    // --------------------------------------------------------
    // STEP 3: OUTPUT TO LED
    // --------------------------------------------------------

    // analogWrite() produces a PWM signal.
    // A larger value means a higher duty cycle.
    analogWrite(LED_PIN, pwmValue);

    // --------------------------------------------------------
    // STEP 4: SEND DATA TO THE PC
    // --------------------------------------------------------

    Serial.print("Raw Knob: ");
    Serial.print(potValue);

    Serial.print("  |  PWM Value: ");
    Serial.println(pwmValue);

    // Slow the output slightly so the Serial Monitor
    // remains easy to read.
    delay(50);
}
}
Save

Save the file with Ctrl + S before building.

07 // Code Breakdown

Understand the Code

This is a major leap forward because your ESP32 is now collecting, transforming, and outputting data.

Serial.begin(115200)

This opens the communication channel between the ESP32 and the computer.

115200 is the baud rate. Both sides need to use the same speed or the received text can become unreadable.

analogRead()

This reads the voltage present on the potentiometer's middle pin.

In this project, the raw ADC reading is expected to cover approximately 0–4095.

map()

The ESP32 receives a large range: 0–4095.

The LED control uses: 0–255.

map() scales the value from one range into another.

analogWrite()

The PWM output changes the duty cycle of the output signal.

In this 8-bit brightness range, 0 means no duty cycle and 255 means full duty cycle.

2 // ADC

11 // Engineering Challenge

Add a Shut-Off Threshold

Now we're going to combine analog input with digital decision-making.

Objective

Sometimes a potentiometer isn't perfectly precise. When turned all the way down, it may still report a small value such as 15.

That could leave the LED glowing faintly.

Requirements

Add an if / else statement after reading the knob.

If potValue < 100 , force pwmValue = 0 .

Otherwise, let map() perform the normal conversion.

Think Like an Engineer

The potentiometer produces continuous data, but your program can still make discrete decisions about that data.

That's the bridge between analog measurements and digital logic.

12 // Debugging

Troubleshooting

If something goes wrong, don't panic. Debug the signal path one stage at a time.

Strange Question Marks

Seeing characters like ⸮⸮⸮?

Your Serial Monitor is probably using the wrong baud rate.

Check that it uses: 115200 .

LED Only Changes at the End

Check the potentiometer wiring.

The middle leg must connect to D34.

Make sure the outer legs connect to 3V3 and GND.

Numbers Don't Change

The potentiometer may not be receiving power.

Verify: 3V3 → outer leg and GND → other outer leg .

LED Doesn't Light

Check LED orientation.

The long leg is normally the anode and the short leg is normally the cathode.

Also verify the LED is connected through the recommended resistor.

Debugging Strategy

Don't randomly change everything. Follow the pipeline: Pot → D34 → analogRead() → map() → PWM → LED .

The Serial Monitor is especially useful because it lets you verify whether the input values are actually changing.

13 // Vocabulary

New Words

These terms are going to appear everywhere in embedded systems.

Word Meaning
Analog A continuous range of values, such as volume, temperature, speed, or brightness.
PWM Pulse Width Modulation. Rapidly switching a digital output to control its average effect.
Potentiometer A variable resistor commonly used as a physical knob or adjustable voltage divider.
Serial Monitor A text interface that lets the ESP32 send data back to the computer over serial communication.
Baud Rate The configured symbol/data rate used by a serial communication connection. This project uses 115200.
ADC Analog-to-Digital Converter. Hardware that converts a measured analog voltage into a numerical digital representation.
Duty Cycle The percentage of a PWM cycle during which the signal is HIGH.
