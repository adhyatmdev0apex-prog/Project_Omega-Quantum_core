03 / CIRCUIT

🔌 2. WIRING

This wiring is a little tricky, so take your time!

LED CONNECTION
1
Connect the LED long leg to D25.
2
Connect the LED short leg to the blue GND rail, through the recommended 220–330Ω series resistor.
LDR + VOLTAGE DIVIDER
1
Push the LDR into the breadboard. It does not have a positive or negative side, so either orientation works.
2
Connect one leg of the LDR to 3V3.
3
Connect the other LDR leg to an empty breadboard row.
4
Connect one end of the 10kΩ resistor to that exact same row.
5
Connect the other end of the 10kΩ resistor to the blue GND rail.
6
Connect that shared middle row to D34 on the ESP32. 
 ESP32          BREADBOARD
 3V3 ────────► LDR Leg 1
 
 D34 ────────► [Shared Row]: LDR Leg 2 AND Resistor Leg 1
 
 GND ────────► [Blue Power Rail]
                      ▲
                      │ (Resistor Leg 2 AND LED Short Leg
                      │  connect here)
                      
  D25 ────────► LED Long Leg
🧠 The important row

The LDR's second leg, one side of the 10kΩ resistor, and the wire going to D34 must all meet at the same breadboard row. That shared point is the voltage-divider output.

05 / SOURCE CODE

📄 4. COMPLETE CODE

Delete the default code and paste this in!

C++ 
/*
 * ============================================================
 * MY BRO'S TWELFTH ESP32 PROGRAM: AUTOMATIC NIGHT LIGHT
 * ============================================================
 */
#include "Arduino.h"

const int SENSOR_PIN = 34; // Where we read the LDR
const int LED_PIN = 25;     // Where our night light is connected

// We set a threshold limit.
// Any number lower than this is considered "DARK".
const int DARK_THRESHOLD = 800;

void setup() {
    // Start the Serial Monitor so we can see the light levels
    Serial.begin(115200);

    // Set the LED as an output
    pinMode(LED_PIN, OUTPUT);
}

void loop() {
    // 1. READ THE SENSOR
    // analogRead() gives us a number from 0 (Pitch Black) to 4095 (Very Bright)
    int lightLevel = analogRead(SENSOR_PIN);

    // 2. PRINT IT TO THE SCREEN
    Serial.print("Current Light Level: ");
    Serial.println(lightLevel);

    // 3. DECISION MAKING (THRESHOLD LOGIC)
    if (lightLevel < DARK_THRESHOLD) {
        // It is darker than our threshold! Turn the security light ON!
        digitalWrite(LED_PIN, HIGH);
        Serial.println(" -> Status: DARK (Light ON)");
    }
    else {
        // It is brighter than our threshold! Turn the light OFF!
        digitalWrite(LED_PIN, LOW);
        Serial.println(" -> Status: DAYTIME (Light OFF)");
    }

    // Wait a little bit before checking again
    delay(200);
}

Save your code with Ctrl + S.

06 / CODE DECODE

🧠 5. UNDERSTAND THE CODE

DARK_THRESHOLD

const int DARK_THRESHOLD = 800;

This is the brain of the operation. By making it a variable at the top of the code, we can easily tune the sensitivity of our night light without digging through the loop().

Threshold Trigger

if (lightLevel < DARK_THRESHOLD)

This asks the ESP32: "Is the current reading LESS THAN our strict limit?"

If yes, the code treats the environment as dark and turns the LED on.

Logging Data

The Serial Monitor prints both the sensor number and the decision.

That means you can see not only the raw measurement, but also exactly what decision the ESP32 made.

Automatic Decision

There is no button telling the ESP32 what to do.

The sensor provides the data, and the threshold provides the rule.

analogRead(SENSOR_PIN)
↓
Get lightLevel
↓
Compare with 800
↓
Below threshold?
↓
DARK → 💡 ON
DAYTIME → 💡 OFF
📌 Sensor readings

With the default Arduino-ESP32 ADC configuration, analogRead() commonly gives a 12-bit reading in the range 0–4095. Real sensor readings depend on the circuit, resistor, lighting, board, and ADC behavior, so use the Serial Monitor to calibrate your threshold.

🔥 9. CHALLENGE

Build a "Twilight Mode" Night Light

Let's combine Project 10 (Analog PWM) with Project 12 (Sensors).

Instead of simply turning the LED ON or OFF, make its brightness depend on the amount of darkness.

🎯 Your Objective

Create a smooth twilight system where the LED gradually becomes brighter as the environment becomes darker.

1
Instead of just using digitalWrite(), use: analogWrite(LED_PIN, pwmValue).
2
If it is extremely bright, the LED should be OFF (0).
3
If it is sort of dim, the LED should glow halfway: ~127.
4
If it is pitch black, the LED should be at maximum brightness: 255.
Hint 
int pwmValue = map(lightLevel, 0, 4095, 255, 0);
pwmValue = constrain(pwmValue, 0, 255);

analogWrite(LED_PIN, pwmValue);
🧠 Think about the direction

Notice that the mapping goes from 255 down to 0. That's because lower light readings mean darker conditions, and darker conditions should produce more LED brightness.

11 / DEBUGGING

🐛 10. TROUBLESHOOTING

The number is stuck at 0 or 4095

Your voltage divider is probably wired incorrectly.

  • Make sure the LDR and 10kΩ resistor share exactly one breadboard row.
  • Make sure the D34 wire is plugged into that exact same shared row.
  • Check that the other LDR leg goes to 3V3.
  • Check that the other resistor leg goes to GND.

The LED never turns on

Look at the Serial Monitor. Does the number actually fall below 800 when you cover the LDR?

If it only drops to something like 1000, change:

C++ 
const int DARK_THRESHOLD = 1200;

Now the LED will trigger when the reading falls below 1200.

LED orientation

If the sensor logic looks correct but the LED doesn't light, check the LED orientation and make sure the LED has the recommended series resistor.

🔎 Debug the data first

The Serial Monitor tells you what the ESP32 actually sees. Before changing the code randomly, inspect the sensor reading and compare it with your threshold.

12 / VOCABULARY

🧠 11. NEW VOCABULARY

Word Meaning
LDR / Photoresistor A sensor that changes its electrical resistance based on how much light is hitting it.
Threshold A specific setpoint or limit in code. Take action only when the value crosses this line.
Calibration Adjusting variables in your code, such as the threshold, to match the real-world physical environment.
Voltage Divider A circuit using two resistive elements to turn a changing resistance into a voltage the ESP32 can read.
