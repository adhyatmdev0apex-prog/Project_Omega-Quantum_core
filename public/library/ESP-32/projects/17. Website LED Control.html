HTTP Routes

A route is a specific path on the web server. The browser requests that path, and the server decides what action belongs to it.

GPIO

Web-to-GPIO

The ESP32 becomes the bridge between software and hardware: HTTP request in, GPIO action out.

The Big Idea

Your phone does not directly control the GPIO pin. Your phone sends an HTTP request to the ESP32. The ESP32 interprets that request and changes the GPIO.

03 / Wiring

Bring Back the LED

Time to reconnect physical hardware. This is the same basic LED circuit you've used before.

LED Circuit

GPIO 2
+

LED Long Leg

Connect the LED's long leg (anode) to D2 / GPIO 2 through a 220–330 Ω resistor.

−

LED Short Leg

Connect the LED's short leg (cathode) to the breadboard's blue GND rail. 

 ESP32                         BREADBOARD

 D2 / GPIO 2 ──[220–330Ω]────► LED LONG LEG (+)

 GND ────────────────────────► [BLUE GND RAIL]

LED safety: Always use a 220–330 Ω current-limiting resistor in series with the LED. Do not connect a bare LED directly between a GPIO pin and GND.

05 / Complete Code

The Web-Controlled GPIO

Delete the default code and paste this into src/main.cpp.

C++ 
/*
 * ============================================================
 * MY BRO'S SEVENTEENTH ESP32 PROGRAM: WEB GPIO CONTROL
 * ============================================================
 */

#include <WiFi.h>
#include <WebServer.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

const int LED_PIN = 2;

// ============================================================
// 1. THE HOMEPAGE ROUTE ("/")
// ============================================================
void handle_Homepage() {
    String html = "<h1>ESP32 Smart Light Control</h1>";
    html += "<p>Click a button to control the physical LED:</p>";

    // HTML Links that act as buttons pointing to our routes
    html += "<p><a href=\"/on\">";
    html += "<button style=\"font-size:20px;background:green;color:white;\">";
    html += "TURN ON";
    html += "</button></a></p>";

    html += "<p><a href=\"/off\">";
    html += "<button style=\"font-size:20px;background:red;color:white;\">";
    html += "TURN OFF";
    html += "</button></a></p>";

    server.send(200, "text/html", html);
}

// ============================================================
// 2. THE "TURN ON" ROUTE ("/on")
// ============================================================
void handle_On() {
    digitalWrite(LED_PIN, HIGH);

    String html = "<h1>Light is ON!</h1>";
    html += "<p><a href=\"/\">Back to Home</a></p>";

    server.send(200, "text/html", html);
}

// ============================================================
// 3. THE "TURN OFF" ROUTE ("/off")
// ============================================================
void handle_Off() {
    digitalWrite(LED_PIN, LOW);

    String html = "<h1>Light is OFF!</h1>";
    html += "<p><a href=\"/\">Back to Home</a></p>";

    server.send(200, "text/html", html);
}

void setup() {
    Serial.begin(115200);

    pinMode(LED_PIN, OUTPUT);

    // Connect to Wi-Fi
    WiFi.begin(ssid, password);

    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }

    Serial.println("\nWi-Fi Connected!");

    Serial.print("Open this IP on your phone: http://");
    Serial.println(WiFi.localIP());

    // Register our routes
    server.on("/", handle_Homepage);
    server.on("/on", handle_On);
    server.on("/off", handle_Off);

    // Start the server
    server.begin();

    Serial.println("Web server started.");
}

void loop() {
    // Listen for incoming browser requests
    server.handleClient();
}
Before Uploading

Replace the Wi-Fi placeholders with your actual local Wi-Fi credentials on your development machine. If you're using this project publicly, keep those real credentials out of the repository.

11 / Troubleshooting

Debug the Web Bridge

When a web-controlled device fails, debug the chain: phone → Wi-Fi → HTTP → route → GPIO.

01

Button gives an error

Check that the link contains the correct leading slash: href="/on" rather than href="on" .

02

Page won't load

Make sure the phone and ESP32 are on the same local Wi-Fi network and that you are typing the ESP32 IP into the browser's URL bar.

03

LED doesn't change

Check the LED wiring, resistor, GND connection, and that the code uses GPIO 2 as LED_PIN .

04

Website feels clunky

That's expected. Each button is a normal HTTP link, so the browser requests another page and reloads the document.

Problem Check Likely Cause
Page won't load Phone Wi-Fi Phone and ESP32 are not on the same local network.
404 / missing route server.on() The route was not registered or the URL path doesn't match.
LED stays OFF D2 + resistor + GND Hardware wiring or GPIO mismatch.
Blank response server.send() The route function may not be sending a valid response.
Network Reality

This project controls the ESP32 over your local network . The phrase "anywhere in my house" means any place where your phone can reach the ESP32 through that same network. This project does not expose the ESP32 directly to the public Internet.

12 / New Vocabulary

Words You Now Own

These terms will become extremely important as we build larger IoT systems.

Word Meaning
Route / Endpoint A specific URL path on a server, such as /on or /off , that can trigger a particular action.
HTTP Request A message sent by a client such as a browser to a server asking for a resource or action.
GPIO A General-Purpose Input/Output pin used by the ESP32 to interact with electrical hardware.
Web-to-GPIO Using a web request as the trigger for a physical GPIO operation.

Client

Your smartphone browser is the client. It sends HTTP requests to the ESP32.

Server

Your ESP32 is the server. It listens for requests and decides how to respond.
