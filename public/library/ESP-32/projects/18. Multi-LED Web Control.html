03 // CONCEPTS

What Are We Learning?

Today has two important web-development concepts: mobile scaling and HTTP redirects.

1. Mobile Viewport

In the previous project, the webpage could look small or awkward on a phone.

Today we add: 

<meta name="viewport" content="width=device-width, initial-scale=1">

This tells the mobile browser to use the device's actual viewport width and scale the webpage appropriately.

Think of it as telling the browser: "This page is designed for the screen you're holding."

2. HTTP Redirects

In Project 17, pressing ON took you to a confirmation page.

Then you had to press "Back to Home."

That's clunky.

Project 18 uses an HTTP 303 redirect.

The ESP32 changes the LED and tells the browser:

"The request succeeded. Now go back to the dashboard."

#include 

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

// Name our pins like rooms in a house
const int LED_LIVING = 2;
const int LED_KITCHEN = 4;
const int LED_BEDROOM = 5;

// ============================================================
// 1. THE MAIN DASHBOARD ("/")
// ============================================================
void handle_Homepage() {
// Make the webpage scale correctly on mobile phones
String html = "";

 
html += "<h1>🏠 Smart Home Dashboard</h1>";

// Living Room Controls (LED 1)
html += "<h3>Living Room</h3>";
html += "<a href=\"/living/on\"><button style=\"font-size:18px; background:green; color:white; padding:10px;\">ON</button></a> ";
html += "<a href=\"/living/off\"><button style=\"font-size:18px; background:red; color:white; padding:10px;\">OFF</button></a>";

// Kitchen Controls (LED 2)
html += "<h3>Kitchen</h3>";
html += "<a href=\"/kitchen/on\"><button style=\"font-size:18px; background:green; color:white; padding:10px;\">ON</button></a> ";
html += "<a href=\"/kitchen/off\"><button style=\"font-size:18px; background:red; color:white; padding:10px;\">OFF</button></a>";

// Bedroom Controls (LED 3)
html += "<h3>Bedroom</h3>";
html += "<a href=\"/bedroom/on\"><button style=\"font-size:18px; background:green; color:white; padding:10px;\">ON</button></a> ";
html += "<a href=\"/bedroom/off\"><button style=\"font-size:18px; background:red; color:white; padding:10px;\">OFF</button></a>";

html += "</body></html>";

server.send(200, "text/html", html);
 

}

// ============================================================
// 2. THE ROUTE FUNCTIONS
// ============================================================

// --- LIVING ROOM ---
void handle_LivingOn() {
digitalWrite(LED_LIVING, HIGH);

 
server.sendHeader("Location", "/");
server.send(303);
 

}

void handle_LivingOff() {
digitalWrite(LED_LIVING, LOW);

 
server.sendHeader("Location", "/");
server.send(303);
 

}

// --- KITCHEN ---
void handle_KitchenOn() {
digitalWrite(LED_KITCHEN, HIGH);

 
server.sendHeader("Location", "/");
server.send(303);
 

}

void handle_KitchenOff() {
digitalWrite(LED_KITCHEN, LOW);

 
server.sendHeader("Location", "/");
server.send(303);
 

}

// --- BEDROOM ---
void handle_BedroomOn() {
digitalWrite(LED_BEDROOM, HIGH);

 
server.sendHeader("Location", "/");
server.send(303);
 

}

void handle_BedroomOff() {
digitalWrite(LED_BEDROOM, LOW);

 
server.sendHeader("Location", "/");
server.send(303);

// ============================================================
// SETUP & LOOP
// ============================================================
void setup() {
Serial.begin(115200);

 
pinMode(LED_LIVING, OUTPUT);
pinMode(LED_KITCHEN, OUTPUT);
pinMode(LED_BEDROOM, OUTPUT);

WiFi.begin(ssid, password);

while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
}

Serial.println("\n🔥 Wi-Fi Connected!");

Serial.print("Open this IP on your phone: http://");
Serial.println(WiFi.localIP());

// Register ALL our routes
server.on("/", handle_Homepage);

server.on("/living/on", handle_LivingOn);
server.on("/living/off", handle_LivingOff);

server.on("/kitchen/on", handle_KitchenOn);
server.on("/kitchen/off", handle_KitchenOff);

server.on("/bedroom/on", handle_BedroomOn);
server.on("/bedroom/off", handle_BedroomOff);

server.begin();
 

}

void loop() {
server.handleClient();
}

07 // CODE DECODE

Understand the Code

This is where the architecture starts becoming important. We aren't just writing more lines; we're organizing a small web application.

The Viewport Tag

The homepage begins with: 

<meta name="viewport" content="width=device-width, initial-scale=1">

This tells the browser that the layout should use the device's actual viewport.

Without it, mobile browsers can render a desktop-oriented page at an awkward scale.

Route Registration

This line connects a URL path to a function: 

server.on("/living/on", handle_LivingOn);

When the browser requests /living/on, the ESP32 executes handle_LivingOn().

Changing the GPIO

Inside the route: 

digitalWrite(LED_LIVING, HIGH);

The web request has now crossed the software/hardware boundary.

Browser command → HTTP route → GPIO output.

HTTP 303 Redirect 
server.sendHeader("Location", "/");
 

server.send(303);

Location says where the browser should go next.

303 tells the browser that the request succeeded and it should follow the new location.

12 // DEBUG

Troubleshooting

Web servers introduce a new class of problems: the browser can request something that the ESP32 doesn't know how to handle.

"Page Not Found"

Did you forget to register the route? 

server.on("/kitchen/on", handle_KitchenOn);

The path in the browser must match the path registered by the server.

Page Stuck Loading

Check that both redirect lines exist: 

server.sendHeader("Location", "/");
 

server.send(303);

The redirect tells the browser where to go next and provides the HTTP status.

C++ String Errors

HTML attributes contain quotation marks. Inside a C++ string, those quotes must be escaped. 

href=\"/living/on\"

Without the backslash, C++ may interpret the quote as the end of the string.

One LED Doesn't Work
  • Check the GPIO number.
  • Check LED polarity.
  • Check the resistor connection.
  • Check the shared GND rail.
  • Make sure the route controls the same pin used by that LED.
Phone Can't Open IP
  • Confirm the ESP32 connected to Wi-Fi.
  • Confirm the phone is on the same local network.
  • Check the IP printed by Serial Monitor.
  • Make sure you typed the IP correctly.
  • Some guest networks isolate devices from each other.
Wi-Fi Never Connects
  • ESP32 Wi-Fi uses 2.4 GHz networks.
  • Check SSID spelling.
  • Check password capitalization.
  • Avoid captive-portal networks for this basic project.
🔐 Security reminder Never publish your real Wi-Fi password inside main.cpp. Keep credentials private and use placeholders in source code that will be shared publicly.

These words are going to become increasingly important as we move deeper into networking and web development.

Dashboard A user interface that organizes controls and information for multiple systems.
Route A URL path handled by a specific server function.
Endpoint A specific network-accessible operation or destination.
HTTP Request A message sent by a client such as a browser asking a server to perform an operation or return data.
