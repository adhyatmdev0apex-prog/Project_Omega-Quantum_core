03 // CONCEPTS

What Are We Learning?

01 · DATA CASTING

Turning Numbers Into Text

A sensor reading such as 24.5 is a numeric value.

Our HTML is text. So we use String() to convert the number into text that can be inserted into the HTML string.

C++ 
String(temp)

Conceptually:

24.5 float
→
"24.5" text
→
HTML browser
02 · META REFRESH

Automatic Page Reloading

In Project 19, you manually refreshed the webpage to see new hardware state.

A weather dashboard should not require you to constantly tap Refresh.

The HTML meta refresh tag tells the browser to request the page again after a specified number of seconds.

HTML 
<meta http-equiv="refresh" content="5">

06 // SOURCE CODE

Complete Code

Before uploading: Replace the Wi-Fi placeholders with your actual local network credentials.
C++ · Arduino 
/*
 * ============================================================
 * MY BRO'S TWENTIETH ESP32 PROGRAM: WEB SENSOR DASHBOARD
 * ============================================================
 */

#include <WiFi.h>
#include <WebServer.h>
#include "DHT.h"

// Wi-Fi credentials
const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

// ============================================================
// DHT11 CONFIGURATION
// ============================================================

const int DHT_PIN = 4;

#define DHT_TYPE DHT11

DHT dht(DHT_PIN, DHT_TYPE);

// ============================================================
// LDR CONFIGURATION
// ============================================================

const int LDR_PIN = 34;

// ============================================================
// LIVE DASHBOARD ROUTE
// ============================================================

void handle_Homepage() {

    // --------------------------------------------------------
    // 1. READ THE SENSORS
    // --------------------------------------------------------

    float temp = dht.readTemperature();
    float hum = dht.readHumidity();

    int light = analogRead(LDR_PIN);

    // --------------------------------------------------------
    // 2. START BUILDING THE HTML
    // --------------------------------------------------------

    String html =
        "<!DOCTYPE html>"
        "<html>"
        "<head>"
        "<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">";

    // Automatically reload the webpage every 5 seconds
    html +=
        "<meta http-equiv=\"refresh\" content=\"5\">";

    html +=
        "<style>"
        "body {"
        "font-family: sans-serif;"
        "text-align: center;"
        "margin-top: 50px;"
        "background-color: #f0f8ff;"
        "}"
        "</style>"
        "</head>"
        "<body>";

    html +=
        "<h1>🌍 Smart Home Environment</h1>";

    // --------------------------------------------------------
    // 3. CHECK FOR DHT11 ERRORS
    // --------------------------------------------------------

    if (isnan(temp) || isnan(hum)) {

        html +=
            "<h2>"
            "<span style=\"color:red;\">"
            "Sensor Error! Check DHT11 Wires."
            "</span>"
            "</h2>";

    }
    else {

        // ----------------------------------------------------
        // 4. INSERT SENSOR DATA INTO THE HTML
        // ----------------------------------------------------

        html +=
            "<h2>"
            "Temperature: "
            "<span style=\"color:blue;\">"
            + String(temp)
            + " &deg;C"
            "</span>"
            "</h2>";

        html +=
            "<h2>"
            "Humidity: "
            "<span style=\"color:blue;\">"
            + String(hum)
            + " %"
            "</span>"
            "</h2>";
    }

    // --------------------------------------------------------
    // 5. DISPLAY THE LDR VALUE
    // --------------------------------------------------------

    html +=
        "<h2>"
        "Light Level: "
        "<span style=\"color:orange;\">"
        + String(light)
        + "</span>"
        "</h2>";

    // --------------------------------------------------------
    // 6. EXPLAIN THE AUTO-REFRESH
    // --------------------------------------------------------

    html +=
        "<p>"
        "<i>"
        "Page auto-refreshes every 5 seconds..."
        "</i>"
        "</p>";

    html +=
        "</body>"
        "</html>";

    // --------------------------------------------------------
    // 7. SEND THE PAGE TO THE PHONE
    // --------------------------------------------------------

    server.send(
        200,
        "text/html",
        html
    );
}

// ============================================================
// SETUP
// ============================================================

void setup() {

    Serial.begin(115200);

    // Start the DHT11
    dht.begin();

    // Start Wi-Fi connection
    WiFi.begin(
        ssid,
        password
    );

    while (
        WiFi.status() != WL_CONNECTED
    ) {

        delay(500);

        Serial.print(".");
    }

    Serial.println(
        "\n🔥 Wi-Fi Connected!"
    );

    Serial.print(
        "Open this IP: http://"
    );

    Serial.println(
        WiFi.localIP()
    );

    // Register homepage
    server.on(
        "/",
        handle_Homepage
    );

    // Start the web server
    server.begin();
}

// ============================================================
// LOOP
// ============================================================

void loop() {

    // Always listen for browser requests
    server.handleClient();
}
Save the file with Ctrl + S before building.
07 // CODE BREAKDOWN

Understand the Code

DHT11

Reading Temperature

C++ 
float temp = dht.readTemperature();

The DHT11 returns a decimal measurement, so we store it in a float .

HUMIDITY

Reading Humidity

C++ 
float hum = dht.readHumidity();

Humidity is also stored as a decimal value, so a float is appropriate.

LDR

Reading Light

C++ 
int light = analogRead(LDR_PIN);

The ESP32 reads the analog voltage and returns a numeric value. In this project that value is represented by the ESP32's ADC reading.

STRING()

Data Casting

C++ 
String(temp)

This converts the numeric value into a String representation so it can be concatenated into the HTML.

CONCATENATION

Gluing HTML Together

The + operator joins pieces of text.

C++ 
html +=
    "Temperature: "
    + String(temp)
    + " °C";

Think of the final HTML as a puzzle assembled piece by piece by the ESP32.

Sensor errors: isnan() checks whether the DHT11 result is an invalid numeric value. That lets the program display an error message instead of blindly presenting bad sensor data.

10 // EXPERIMENT

Make It Feel More Live

Five seconds works, but for a dashboard it can feel slow.

Let's reduce the refresh interval.

BEFORE 
html += "<meta http-equiv=\"refresh\" content=\"5\">";
AFTER 
html += "<meta http-equiv=\"refresh\" content=\"2\">";
5 SECONDS

Less Network Activity

The browser waits longer between requests. This produces fewer page reloads.

2 SECONDS

Faster Updates

The browser requests new sensor data more frequently, making the dashboard feel more responsive.

But notice the trade-off: Every refresh downloads the entire HTML page again. Faster refreshes mean more repeated network traffic and more work for the ESP32 web server.
And this is exactly why Project 21 exists. We will stop reloading the entire page and instead use JavaScript to request only the data that changed.

12 // DEBUG

Troubleshooting

DHT11

"Sensor Error!"

  • Check DHT11 VCC → 3V3.
  • Check DATA → D4.
  • Check GND.
  • Verify your sensor's exact pinout.
  • Check that the DHT library dependencies are present in platformio.ini.
PLATFORMIO

DHT.h not found

The project probably does not have the DHT library dependency configured.

Check platformio.ini and make sure the lib_deps entries are present.

AUTO REFRESH

Page does not refresh

Check that the HTML contains:

HTML 
<meta http-equiv="refresh" content="5">

Remember that quotation marks inside a C++ string need escaping with \" .

LDR

Light value looks wrong

  • Check the 3V3 connection.
  • Make sure the 10kΩ resistor connects from the shared row to GND.
  • Make sure D34 connects to the shared row.
  • Try covering the LDR and compare the reading.
WI-FI

Phone cannot open the dashboard

  • Confirm the ESP32 successfully connected to Wi-Fi.
  • Check the IP address printed in Serial Monitor.
  • Make sure your phone and ESP32 are on the same local network.
  • Make sure the ESP32 is still powered.
Network security: This is a local-network prototype. Do not expose the ESP32's web server directly to the public Internet without proper authentication, authorization, transport security, and network configuration.
