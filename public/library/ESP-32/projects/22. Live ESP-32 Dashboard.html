03 / CORE CONCEPTS

What Are We Learning?

Today we upgrade from individual text values to structured data.

Concept 01

JSON

JSON means JavaScript Object Notation . It is a structured text format commonly used to exchange data between software systems.

JSON 
{"temperature":24.5,"humidity":45.0,"light":1500}
Concept 02

Key-Value Pairs

JSON stores information using labels called keys and their associated values.

  • temperature → 24.5
  • humidity → 45.0
  • light → 1500
Concept 03

One Data Package

Instead of making JavaScript request three separate values, it asks the ESP32 for one /data package.

Concept 04

JSON Parsing

JavaScript can convert the JSON response into an object and access individual values with dot notation.

data.temperature

04 / HARDWARE

Wiring

Exact same sensor wiring as Project 20. No LED is required for this project.

Sensor 01

DHT11

  • VCC (+) → 3V3
  • DATA (S) → D4
  • GND (-) → Blue GND rail
Sensor 02

LDR Voltage Divider

  • LDR leg 1 → 3V3
  • LDR leg 2 → shared middle row
  • 10kΩ resistor → same middle row
  • Other resistor end → GND
  • Shared row → D34

Why the LDR gives us a number

The LDR changes resistance depending on the amount of light. Together with the 10kΩ resistor it forms a voltage divider. GPIO34 reads the resulting analog voltage and analogRead() converts it into a numerical reading.

DHT11 Pinout Warning

DHT11 modules and bare 4-pin sensors can have different physical layouts. For a bare sensor, verify the exact pinout from the sensor/module markings before powering it.

06 / FIRMWARE

Complete Code

Now we build the ESP32 web server, the JSON API endpoint and the JavaScript dashboard.

Critical

Replace YOUR_WIFI_NAME and YOUR_PASSWORD with your actual network credentials before uploading.

C++ 
/*
 * ============================================================
 * MY BRO'S TWENTY-SECOND ESP32 PROGRAM: JSON DASHBOARD
 * ============================================================
 */

#include <WiFi.h>
#include <WebServer.h>
#include "DHT.h"

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

const int DHT_PIN = 4;
#define DHT_TYPE DHT11
DHT dht(DHT_PIN, DHT_TYPE);

const int LDR_PIN = 34;

// ============================================================
// 1. THE HOMEPAGE (WITH JAVASCRIPT JSON PARSER)
// ============================================================
void handle_Homepage() {
    String html = "<!DOCTYPE html><html><head><meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">";
    html += "<style>body { font-family: sans-serif; text-align: center; margin-top: 50px; background-color: #222; color: #fff; }</style>";

    // --------------------------------------------------------
    // JAVASCRIPT
    // --------------------------------------------------------
    html += "<script>";
    html += "function updateData() {";

    // Fetch the JSON package
    html += "  fetch('/data').then(response => response.json()).then(data => {";

    // Unpack the JSON and update all three HTML IDs instantly!
    html += "    document.getElementById('temp_val').innerHTML = data.temperature;";
    html += "    document.getElementById('hum_val').innerHTML = data.humidity;";
    html += "    document.getElementById('light_val').innerHTML = data.light;";

    html += "  });";
    html += "}";

    // Run this function every 1 second
    html += "setInterval(updateData, 1000);";
    html += "</script>";
    // --------------------------------------------------------

    html += "</head><body>";
    html += "<h1>🚀 Live Pro Dashboard</h1>";

    // Notice the specific ID nametags!
    html += "<h2>Temperature: <span id=\"temp_val\" style=\"color:#ff6666;\">--</span> &deg;C</h2>";
    html += "<h2>Humidity: <span id=\"hum_val\" style=\"color:#66b3ff;\">--</span> %</h2>";
    html += "<h2>Light Level: <span id=\"light_val\" style=\"color:#ffcc00;\">--</span></h2>";

    html += "</body></html>";

    server.send(200, "text/html", html);
}

// ============================================================
// 2. THE JSON DATA ROUTE (/data)
// ============================================================
void handle_Data() {
    float t = dht.readTemperature();
    float h = dht.readHumidity();
    int l = analogRead(LDR_PIN);

    // Build the JSON String
    // We use \" to tell C++ to put an actual quotation mark
    // inside the string!
    String json = "{";
    json += "\"temperature\":" + String(t) + ",";
    json += "\"humidity\":" + String(h) + ",";
    json += "\"light\":" + String(l);
    json += "}";

    // Tell the browser that this is JSON data.
    server.send(200, "application/json", json);
}

// ============================================================
// SETUP & LOOP
// ============================================================
void setup() {
    Serial.begin(115200);
    dht.begin();

    WiFi.begin(ssid, password);

    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }

    Serial.println("\n🔥 Wi-Fi Connected!");
    Serial.print("Open this IP: http://");
    Serial.println(WiFi.localIP());

    server.on("/", handle_Homepage);
    server.on("/data", handle_Data);

    server.begin();
}

void loop() {
    server.handleClient();
}

07 / CODE DECODE

Understand the Code

This is the important part. Don't just paste the code — understand the architecture.

Part 01

Building JSON in C++

The ESP32 manually constructs the JSON string.

JSON 
{"temperature":24.50,"humidity":45.00,"light":2048}

The \" characters are escaped quotation marks. They allow quotation marks to exist inside a C++ string.

Part 02

application/json

The server sends:

application/json

This tells the browser that the response contains JSON data rather than a normal HTML webpage.

Part 03

response.json()

JavaScript receives the response and converts the JSON into a JavaScript object.

JavaScript 
fetch('/data')
    .then(response => response.json())
    .then(data => {
        // data is now an object
    });
Part 04

Dot Notation

Because the JSON has keys, JavaScript can directly access the required value.

data.temperature

The same idea works for data.humidity and data.light .

The Architecture

The ESP32 is acting as a small HTTP data server. The /data route is effectively an API endpoint that exposes the current sensor measurements. The browser is the client consuming that API.

12 / DEBUG

Troubleshooting

JSON is strict. Tiny formatting mistakes can stop the browser from parsing the response.

Problem

Numbers Never Appear

The page loads but remains -- .

Open /data directly. If the returned text is malformed, check the JSON construction in C++.

Problem

JSON Is Broken

Check every comma and quotation mark. JSON syntax must be valid.

Remember that C++ uses \" when a quotation mark needs to exist inside a string literal.

Problem

One Value Works

If temperature works but humidity or light does not, check the matching HTML IDs and JavaScript property names.

temp_val ↔ temperature
Problem

DHT11 Error

Check VCC, DATA and GND. Also verify that your physical DHT11 pinout matches the module or sensor you actually have.

Problem

LDR Stuck

If the light reading stays around one extreme, inspect the voltage-divider connections and confirm D34 is connected to the shared middle node.

Problem

Wi-Fi Fails

Verify SSID and password exactly. Wi-Fi credentials are case-sensitive. Standard ESP32 Wi-Fi operation uses 2.4 GHz networks.

Debug Like a Developer

Don't immediately rewrite the entire program. Test the layers separately: hardware → sensor reading → /data API → JavaScript parsing → HTML display .

13 / VOCABULARY

New Vocabulary

These words will become extremely important as your ESP32 projects turn into real IoT applications.

Word Meaning
JSON JavaScript Object Notation. A structured text format used to represent and exchange data.
Key-Value Pair A JSON structure where a key identifies a piece of data and its value contains the associated information.
API Endpoint A specific server route designed to provide data or perform an operation. Here, /data returns sensor data.
JSON Parsing Converting JSON data into a structure that the receiving program can work with.
Data Package A collection of related information grouped together so it can be sent as one unit.
HTTP The protocol used by the browser and ESP32 web server to exchange requests and responses.
