Step 03

What Are We Learning?

Today we are learning about OLED screens and I2C communication.

01 // What is an OLED?

OLED stands for Organic Light-Emitting Diode.

Our tiny 0.96-inch screen is made of 128 columns and 64 rows of microscopic pixels.

We use an X/Y coordinate system to tell the screen exactly where to draw text or shapes.

02 // I2C Communication

If the screen has 128 × 64 = 8,192 pixels, how do we control it without needing thousands of wires?

We use a communication protocol called I2C.

It uses exactly two communication wires: SCL and SDA.

SCL — Serial Clock

Think of SCL as the metronome that keeps the communication synchronized.

SDA — Serial Data

SDA carries the actual data bits being sent to the OLED.

ESP32 I2C pins used today: D22 = SCL and D21 = SDA.

C++ 
/*
 * ============================================================
 * MY BRO'S TWENTY-FOURTH ESP32 PROGRAM: WEB + OLED
 * ============================================================
 */

#include <WiFi.h>
#include <WebServer.h>
#include <Wire.h>               // The I2C communication library
#include <Adafruit_GFX.h>       // The graphics library
#include <Adafruit_SSD1306.h>   // The specific OLED screen library

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

WebServer server(80);

// Set up the OLED display dimensions (128 pixels wide, 64 pixels high)
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

Adafruit_SSD1306 display(
    SCREEN_WIDTH,
    SCREEN_HEIGHT,
    &Wire,
    -1
);


// ============================================================
// HELPER FUNCTION: DRAW TEXT ON THE OLED
// ============================================================
void updateScreen(String message) {
    display.clearDisplay();       // Wipe the screen clean
    display.setTextSize(2);       // Medium text size
    display.setTextColor(WHITE);  // Define the display text color
    display.setCursor(0, 20);     // Set X, Y coordinates
    display.println(message);     // Type the message
    display.display();            // Push the buffer to the OLED
}


// ============================================================
// THE WEBPAGE & ROUTES
// ============================================================
void handle_Homepage() {
    String html =
        "<!DOCTYPE html>"
        "<html>"
        "<head>"
        "<meta name=\"viewport\" "
        "content=\"width=device-width, initial-scale=1\">";

    html +=
        "<style>"
        "body { "
        "font-family: sans-serif; "
        "text-align: center; "
        "margin-top: 50px; "
        "background-color: #222; "
        "color: #fff; "
        "}"
        "button { "
        "font-size: 20px; "
        "padding: 15px; "
        "margin: 10px; "
        "width: 80%; "
        "border-radius: 10px; "
        "border: none; "
        "font-weight: bold; "
        "}"
        "</style>"
        "</head>"
        "<body>";

    html += "<h1>🖥️ OLED Status Board</h1>";
    html += "<p>Set the physical screen status:</p>";

    // Buttons that link to our routes
    html +=
        "<a href=\"/status/gaming\">"
        "<button style=\"background-color: #ff3333; color: white;\">"
        "🎮 GAMING MODE"
        "</button>"
        "</a><br>";

    html +=
        "<a href=\"/status/study\">"
        "<button style=\"background-color: #33cc33; color: white;\">"
        "📚 STUDY MODE"
        "</button>"
        "</a><br>";

    html +=
        "<a href=\"/status/sleep\">"
        "<button style=\"background-color: #3333ff; color: white;\">"
        "💤 SLEEP MODE"
        "</button>"
        "</a><br>";

    html +=
        "</body>"
        "</html>";

    server.send(200, "text/html", html);
}


// These routes update the physical screen
// and redirect back to the homepage.

void handle_Gaming() {
    updateScreen("GAMING!");

    server.sendHeader("Location", "/");
    server.send(303);
}


void handle_Study() {
    updateScreen("STUDYING!");

    server.sendHeader("Location", "/");
    server.send(303);
}


void handle_Sleep() {
    updateScreen("Zzz...");

    server.sendHeader("Location", "/");
    server.send(303);
}


// ============================================================
// SETUP & LOOP
// ============================================================
void setup() {

    Serial.begin(115200);

    // 1. BOOT UP THE OLED SCREEN
    // Address 0x3C is standard for many 0.96" OLED modules.
    if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {

        Serial.println("OLED connection FAILED!");

        for (;;) {
            // Freeze if the OLED cannot initialize.
        }
    }

    // Show a welcome message
    updateScreen("BOOTING...");


    // 2. BOOT UP WI-FI
    WiFi.begin(ssid, password);

    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
        Serial.print(".");
    }


    // Display the IP address ON THE ACTUAL OLED SCREEN!
    display.clearDisplay();

    display.setTextSize(1);
    display.setCursor(0, 10);

    display.println("Wi-Fi Connected!");
    display.println("IP Address:");

    display.setTextSize(2);
    display.println(WiFi.localIP());

    display.display();


    // 3. SET UP WEB ROUTES
    server.on("/", handle_Homepage);

    server.on(
        "/status/gaming",
        handle_Gaming
    );

    server.on(
        "/status/study",
        handle_Study
    );

    server.on(
        "/status/sleep",
        handle_Sleep
    );

    server.begin();
}


void loop() {
    server.handleClient();
}
Save your code: Press Ctrl + S.
Step 07

Understand the Code

Now we connect the software concepts to the physical OLED.

display.clearDisplay()

Before drawing new text, we erase the previous screen contents.

Without clearing the display, new letters can be drawn over old letters and create an unreadable glowing mess.

display.setCursor(X, Y)

OLED graphics use coordinates.

The top-left corner is approximately (0, 0).

We use setCursor(0, 20) to move the text downward.

display.display()

This one is extremely important.

The drawing commands first modify the OLED's internal memory buffer. The physical display does not update until display.display() sends that buffered image to the OLED.

Web Route

The architecture: Your smartphone is the remote controller. Wi-Fi carries the HTTP request. The ESP32 runs the command. I2C carries display data to the OLED.

Your Objective

D2 → 220–330Ω resistor → LED long leg → LED short leg → GND.

Step 12

Troubleshooting

Don't panic if the tiny screen stays dark. Diagnose the communication chain.

OLED completely dark

Check the I2C wiring.

  • SCL must go to D22.
  • SDA must go to D21.
  • VCC must go to the correct power pin.
  • GND must be connected correctly.

OLED connection FAILED

Your module may use a different I2C address.

Many 0.96-inch SSD1306 displays use:

0x3C

Some use:

0x3D

Try changing the address in display.begin(...) if your module requires it.

Text overlaps

You probably removed:

display.clearDisplay();

The OLED needs to be cleared before the next message is drawn.

Webpage works, OLED doesn't

This means the Wi-Fi and Web Server parts are probably working, but the OLED side of the chain needs checking.

  • Check SDA/D22 wiring.
  • Check SDA/D21 wiring.
  • Check OLED power.
  • Check I2C address.
Debugging mindset: Break the system into layers: Power → I2C → OLED initialization → Wi-Fi → HTTP route → display update. Don't randomly change everything at once.
