Why the OLED?

The OLED gives our ESP32 a physical interface. Instead of looking at the Serial Monitor, the device itself can display the information it collected.

Why an API?

The ESP32 cannot magically know the current Bitcoin price. It needs to request that information from a server somewhere on the Internet.

05 // Firmware

Complete Code

🚨 Critical: Replace YOUR_WIFI_NAME and YOUR_PASSWORD with your actual Wi-Fi credentials. Never publish real credentials in an open-source repository.
C++ 
/*
 * ============================================================
 * MY BRO'S THIRTY-SECOND ESP32 PROGRAM: LIVE CRYPTO TICKER
 * ============================================================
 */

#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>
#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

const char* ssid = "YOUR_WIFI_NAME";
const char* password = "YOUR_PASSWORD";

// CoinDesk API endpoint for the Bitcoin price feed.
String apiURL = "http://api.coindesk.com/v1/bpi/currentprice.json";

// OLED configuration.
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64

Adafruit_SSD1306 display(
    SCREEN_WIDTH,
    SCREEN_HEIGHT,
    &Wire,
    -1
);

// Timer variables.
unsigned long previousMillis = 0;
const unsigned long interval = 30000;

void setup() {
    Serial.begin(115200);

    // ========================================================
    // 1. START THE OLED
    // ========================================================

    if (!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)) {
        Serial.println("OLED initialization failed.");

        for (;;) {
        }
    }

    display.clearDisplay();
    display.setTextColor(WHITE);

    // Startup splash screen.
    display.setTextSize(2);

    display.setCursor(10, 20);
    display.println("CRYPTO");

    display.setCursor(10, 40);
    display.println("TRACKER");

    display.display();

    delay(2000);

    // ========================================================
    // 2. CONNECT TO WI-FI
    // ========================================================

    display.clearDisplay();
    display.setTextSize(1);
    display.setCursor(0, 20);

    display.println("Connecting Wi-Fi...");
    display.display();

    WiFi.begin(ssid, password);

    while (WiFi.status() != WL_CONNECTED) {
        delay(500);
    }

    display.clearDisplay();
    display.setCursor(0, 20);

    display.println("Wi-Fi Connected!");
    display.display();

    delay(1000);
}

void loop() {

    unsigned long currentMillis = millis();

    // ========================================================
    // API FETCH TIMER
    // ========================================================

    if (
        currentMillis - previousMillis >= interval ||
        previousMillis == 0
    ) {

        previousMillis = currentMillis;

        if (WiFi.status() == WL_CONNECTED) {

            Serial.println(
                "Fetching live Bitcoin price..."
            );

            HTTPClient http;

            http.begin(apiURL);

            int httpResponseCode = http.GET();

            // ====================================================
            // SERVER RESPONSE
            // ====================================================

            if (httpResponseCode == 200) {

                String payload = http.getString();

                // =================================================
                // PARSE JSON
                // =================================================

                JsonDocument doc;

                DeserializationError error =
                    deserializeJson(doc, payload);

                if (error) {

                    Serial.print(
                        "JSON parsing failed: "
                    );

                    Serial.println(error.c_str());

                } else {

                    // Navigate:
                    //
                    // doc
                    //   -> bpi
                    //      -> USD
                    //         -> rate_float

                    float btcPrice =
                        doc["bpi"]["USD"]["rate_float"]
                            .as<float>();

                    Serial.print(
                        "Success! BTC Price: $"
                    );

                    Serial.println(btcPrice, 2);

                    // =================================================
                    // UPDATE OLED
                    // =================================================

                    display.clearDisplay();

                    // Top banner.
                    display.setTextSize(1);
                    display.setCursor(0, 0);

                    display.println(
                        "BITCOIN (BTC/USD)"
                    );

                    display.drawLine(
                        0,
                        10,
                        127,
                        10,
                        WHITE
                    );

                    // Large price.
                    display.setTextSize(2);
                    display.setCursor(0, 30);

                    display.print("$");
                    display.print(
                        btcPrice,
                        2
                    );

                    // LIVE indicator.
                    display.setTextSize(1);
                    display.setCursor(100, 56);

                    display.print("LIVE");

                    display.display();
                }

            } else {

                Serial.print(
                    "HTTP Error Code: "
                );

                Serial.println(httpResponseCode);
            }

            http.end();
        }
    }
}

Save with Ctrl + S.

Why this version is slightly safer: it checks whether ArduinoJson successfully parsed the response before attempting to read the Bitcoin price. That makes API failures much easier to diagnose.

10 // Challenge

Build a Price Trend Indicator

🔥 Your Objective

In real financial dashboards, knowing the current price is useful — but knowing whether the price moved up or down is also important.

Add two LEDs to create a physical trend indicator.

  • Add a Green LED to D2.
  • Add a Red LED to D4.
  • Create: float lastPrice = 0;
  • After extracting btcPrice, compare it with lastPrice.
  • If the price increased, turn the Green LED ON and Red LED OFF.
  • If the price decreased, turn the Red LED ON and Green LED OFF.
  • Finally: lastPrice = btcPrice;
⚠ LED safety: each external LED should have a 220–330Ω current-limiting resistor in series. Do not connect an LED directly between a GPIO pin and GND without current limiting.

Challenge logic

C++ 
float lastPrice = 0;

if (btcPrice > lastPrice) {
    digitalWrite(LED_GREEN, HIGH);
    digitalWrite(LED_RED, LOW);
}
else if (btcPrice < lastPrice) {
    digitalWrite(LED_GREEN, LOW);
    digitalWrite(LED_RED, HIGH);
}

lastPrice = btcPrice;
First reading: because lastPrice starts at zero, the first valid Bitcoin price will appear to be an increase. A more polished implementation can use a boolean such as hasPreviousPrice so the first reading is treated as a baseline instead.
11 // Debugging

Troubleshooting

❌ OLED is blank

Check VCC, GND, SDA, and SCL.

This guide expects:

D21 → SDA
D22 → SCL

Also try changing the I2C address from 0x3C to 0x3D if your particular module uses that address.

❌ HTTP request fails

Look at the HTTP response code in Serial Monitor.

A negative value generally indicates that the HTTP connection itself failed rather than a normal server response.

Check Wi-Fi connectivity and whether the endpoint is reachable.

❌ JSON parsing fails

The API response may not have the structure your code expects.

Remember:

JSON PATH 
bpi
  └── USD
      └── rate_float

If the API changes its response format, this path may need to change.

❌ Price doesn't appear

Verify that:

  • Wi-Fi connected successfully
  • HTTP response was successful
  • JSON parsing succeeded
  • The expected JSON field exists
  • The OLED was initialized correctly

❌ Text overlaps

Make sure display.clearDisplay() is called before drawing the new interface.

Think of the OLED framebuffer like a chalkboard. If you don't erase it, you're drawing the new interface over the old one.

❌ Price looks wrong

Check the currency key and the exact JSON path. Also make sure the API is returning a current response rather than an error document.

Developer debugging rule: don't immediately rewrite your code when something fails. First determine which layer failed: Wi-Fi → HTTP → JSON → data → OLED.
