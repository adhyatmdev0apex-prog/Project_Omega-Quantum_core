The Command Center

Your ESP32 will read a physical sensor, display local and cloud information, serve a web dashboard, receive WebSocket commands, and control physical hardware.

⚠️ Architecture reality check: Two cores do not create magical zero-latency isolation. Network requests can still take time, tasks can still compete for resources, and shared data still needs synchronization. The goal is to design the workload so blocking network operations do not unnecessarily stall unrelated hardware work.

01 // Thread Safety

Core 1 updates values such as the room temperature. Core 0 reads those values to construct WebSocket messages.

We'll protect those shared values using a small FreeRTOS critical section.

02 // Non-Blocking Architecture

An HTTP request to a remote server can take considerably longer than local GPIO work.

By separating responsibilities into tasks, local hardware work can continue while the network task waits for its operation to finish.

🎯 The real lesson: Good embedded architecture is not simply "make it faster." It's about giving each responsibility an appropriate execution model and preventing one slow subsystem from unnecessarily controlling the entire system.

bool ledState = false;

float localTemp = 0.0;

float globalTemp = 0.0;

// FreeRTOS task handles
TaskHandle_t Core0Task;
TaskHandle_t Core1Task;

// Small critical-section lock for shared variables.
// This protects short reads/writes between the two tasks.
portMUX_TYPE stateMux = portMUX_INITIALIZER_UNLOCKED;


// ============================================================
// SAFE SHARED STATE FUNCTIONS
// ============================================================

void setLedState(bool newState) {

    portENTER_CRITICAL(&stateMux);

    ledState = newState;

    portEXIT_CRITICAL(&stateMux);
}


bool getLedState() {

    bool value;

    portENTER_CRITICAL(&stateMux);

    value = ledState;

    portEXIT_CRITICAL(&stateMux);

    return value;
}


void setLocalTemp(float newTemp) {

    portENTER_CRITICAL(&stateMux);

    localTemp = newTemp;

    portEXIT_CRITICAL(&stateMux);
}


float getLocalTemp() {

    float value;

    portENTER_CRITICAL(&stateMux);

    value = localTemp;

    portEXIT_CRITICAL(&stateMux);

    return value;
}


void setGlobalTemp(float newTemp) {

    portENTER_CRITICAL(&stateMux);

    globalTemp = newTemp;

    portEXIT_CRITICAL(&stateMux);
}


float getGlobalTemp() {

    float value;

    portENTER_CRITICAL(&stateMux);

    value = globalTemp;

    portEXIT_CRITICAL(&stateMux);

    return value;
}

// ============================================================
// WEBSOCKET EVENT HANDLER
// ============================================================

void webSocketEvent(
    uint8_t num,
    WStype_t type,
    uint8_t* payload,
    size_t length
) {

    if (type != WStype_TEXT) {
        return;
    }

    String msg =
        String((char*)payload);

    if (msg == "TOGGLE") {

        bool newState =
            !getLedState();

        setLedState(newState);

        digitalWrite(
            LED_PIN,
            newState ? HIGH : LOW
        );
    }
}


// ============================================================
// CORE 0
// NETWORK BOSS
// ============================================================

void Core0Code(void* pvParameters) {

    unsigned long lastApiCheck = 0;

    unsigned long lastWsPush = 0;

    for (;;) {

        // Process normal HTTP requests.
        server.handleClient();

        // Process WebSocket traffic.
        webSocket.loop();

        unsigned long currentMillis =
            millis();

        // ----------------------------------------------------
        // SEND SYSTEM STATE TO CONNECTED BROWSERS
        // ----------------------------------------------------

        if (
            currentMillis - lastWsPush >= 1000
        ) {

            lastWsPush =
                currentMillis;

            bool currentLed =
                getLedState();

            float currentLocalTemp =
                getLocalTemp();

            float currentGlobalTemp =
                getGlobalTemp();

            String wsJson =
                "{"
                "\"led\":" +
                String(currentLed ? "true" : "false") +
                ",\"loc_temp\":" +
                String(currentLocalTemp, 1) +
                ",\"glob_temp\":" +
                String(currentGlobalTemp, 1) +
                "}";

            webSocket.broadcastTXT(
                wsJson
            );
        }

        // ----------------------------------------------------
        // CLOUD API
        // ----------------------------------------------------

        if (
            currentMillis - lastApiCheck >= 30000 ||
            lastApiCheck == 0
        ) {

            lastApiCheck =
                currentMillis;

            if (
                WiFi.status() == WL_CONNECTED
            ) {

                HTTPClient http;

                http.begin(weatherAPI);

                int httpCode =
                    http.GET();

                if (httpCode == 200) {

                    String payload =
                        http.getString();

                    JsonDocument doc;

                    DeserializationError error =
                        deserializeJson(
                            doc,
                            payload
                        );

                    if (!error) {

                        float temperature =
                            doc["current"]["temperature_2m"]
                            | 0.0f;

                        setGlobalTemp(
                            temperature
                        );
                    }
                }

                http.end();
            }
        }

        // Give this task time to yield.
        vTaskDelay(
            10 / portTICK_PERIOD_MS
        );
    }
}


// ============================================================
// CORE 1
// HARDWARE BOSS
// ============================================================

void Core1Code(void* pvParameters) {

    for (;;) {

        // ----------------------------------------------------
        // DHT11
        // ----------------------------------------------------

        float t =
            dht.readTemperature();

        if (!isnan(t)) {

            setLocalTemp(t);
        }

        // ----------------------------------------------------
        // READ SHARED VALUES
        // ----------------------------------------------------

        float roomTemperature =
            getLocalTemp();

        float worldTemperature =
            getGlobalTemp();

        bool currentLed =
            getLedState();

        // ----------------------------------------------------
        // OLED
        // ----------------------------------------------------

        display.clearDisplay();

        display.setTextSize(1);

        display.setTextColor(
            WHITE
        );

        display.setCursor(
            0,
            0
        );

        display.println(
            "ESP32 COMMAND HUB"
        );

        display.drawLine(
            0,
            10,
            128,
            10,
            WHITE
        );

        display.setCursor(
            0,
            15
        );

        display.print(
            "Room:   "
        );

        display.print(
            roomTemperature,
            1
        );

        display.println(
            " C"
        );

        display.setCursor(
            0,
            30
        );

        display.print(
            "London: "
        );

        display.print(
            worldTemperature,
            1
        );

        display.println(
            " C"
        );

        // ----------------------------------------------------
        // LIGHT STATUS
        // ----------------------------------------------------

        if (currentLed) {

            display.fillRoundRect(
                0,
                45,
                128,
                18,
                4,
                WHITE
            );

            display.setTextColor(
                BLACK
            );

            display.setCursor(
                20,
                50
            );

            display.print(
                "LIGHT IS ON!"
            );

            display.setTextColor(
                WHITE
            );
        }

        display.display();

        // DHT11 should not be polled rapidly.
        vTaskDelay(
            2000 / portTICK_PERIOD_MS
        );
    }
}


// ============================================================
// SETUP
// ============================================================

void setup() {

    Serial.begin(115200);

    pinMode(
        LED_PIN,
        OUTPUT
    );

    digitalWrite(
        LED_PIN,
        LOW
    );

    dht.begin();

    // --------------------------------------------------------
    // OLED INITIALIZATION
    // --------------------------------------------------------

    if (
        !display.begin(
            SSD1306_SWITCHCAPVCC,
            0x3C
        )
    ) {

        for (;;) {
            delay(1000);
        }
    }

    display.clearDisplay();

    display.setTextColor(
        WHITE
    );

    display.setTextSize(1);

    display.setCursor(
        0,
        20
    );

    display.println(
        "BOOTING COMMAND HUB..."
    );

    display.display();

    // --------------------------------------------------------
    // WIFI
    // --------------------------------------------------------

    WiFi.begin(
        ssid,
        password
    );

    Serial.print(
        "Connecting to Wi-Fi"
    );

    while (
        WiFi.status() != WL_CONNECTED
    ) {

        delay(500);

        Serial.print(".");
    }

    Serial.println();

    Serial.println(
        "Wi-Fi Connected!"
    );

    Serial.print(
        "Open this IP: http://"
    );

    Serial.println(
        WiFi.localIP()
    );

    // --------------------------------------------------------
    // WEB SERVER
    // --------------------------------------------------------

    server.on(
        "/",
        handle_Homepage
    );

    server.begin();

    // --------------------------------------------------------
    // WEBSOCKET
    // --------------------------------------------------------

    webSocket.begin();

    webSocket.onEvent(
        webSocketEvent
    );

    // --------------------------------------------------------
    // FREE RTOS TASKS
    // --------------------------------------------------------

    xTaskCreatePinnedToCore(
        Core0Code,
        "NetBoss",
        10000,
        NULL,
        1,
        &Core0Task,
        0
    );

    xTaskCreatePinnedToCore(
        Core1Code,
        "HwBoss",
        10000,
        NULL,
        1,
        &Core1Task,
        1
    );

    Serial.println(
        "Command Center tasks started."
    );
}

⏱️ Why this architecture matters: The API request can be slow because it depends on Wi-Fi and an external server. During that network operation, the Core 1 hardware task remains a separate schedulable task. This does not mean every operation in the entire system becomes non-blocking; it means we've isolated one potentially slow responsibility from the local hardware task.

The OLED inversion trick

When the LED is ON, the OLED draws a filled white rounded rectangle and switches text to black. That produces a simple inverted status banner.
